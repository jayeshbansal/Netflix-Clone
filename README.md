# 🎬 Netflix Clone

A responsive **Netflix Landing Page Clone** built using **HTML5** and **CSS3**. This project recreates the look and feel of Netflix's homepage while focusing on responsive web design, clean UI, and modern CSS techniques.

## 🚀 Live Demo

🔗 https://jayeshbansal.github.io/Netflix-Clone/

## ✨ Features

- Responsive design for Desktop, Tablet, and Mobile
- Modern Netflix-inspired UI
- Hero banner section
- Navigation bar
- Feature sections
- FAQ section
- Footer with useful links
- Clean and organized code
- Cross-browser compatible

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries


Simply open `index.html` in your preferred web browser.
